# 台股槓桿監測

個人用的網頁 App（PWA），手機和電腦都能用，可加到手機主畫面。

- **總覽**：大盤融資維持率（全市場／上市／上櫃，民間算法）、官方全市場擔保維持率、追繳／處分戶數、融資餘額、恐慌溫度（台指 VIX 等綜合）、維持率走勢
- **個股**：輸入代號或名稱，查估算融資維持率、融資餘額增減、估算融資均價、近 20 日走勢
- **自選**：用星號加入，依維持率由低到高排列（只存在本機瀏覽器）

## 運作方式

`.github/workflows/update.yml` 每個交易日晚上與隔天早上執行 `scripts/update.py`，
從證交所、櫃買中心、期交所抓公開資料，計算後寫入 `data/`，再發布到 GitHub Pages。

手動重建歷史：Actions → 更新資料並發布 → Run workflow → backfill 填 120。

## 資料檔

- `data/market.json`：每日大盤指標
- `data/stocks.json`：最新一日個股估算（欄位見檔內 `fields`）
- `data/state.json`：個股融資成本估算的累積狀態
